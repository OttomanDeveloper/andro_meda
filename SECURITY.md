# Security Policy

Chronos is a client-side Flutter showcase app — it has no backend, accounts, or
stored secrets — so the security surface is small. Still, if you find something,
we'd like to know.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅        |
| < 1.0   | ❌        |

The latest release on the default branch always receives fixes.

## Reporting a vulnerability

**Please do not open a public issue for security reports.**

Instead, report privately using either:

- GitHub's **[Private vulnerability reporting](https://github.com/OttomanDeveloper/andro_meda/security/advisories/new)**
  (Security → Report a vulnerability), or
- Email **usman243786@gmail.com** with the details.

Please include:

- A description of the issue and its impact.
- Steps to reproduce (or a proof of concept).
- The affected version, platform, and browser if relevant.

You can expect an acknowledgement within **5 business days**. Once the issue is
confirmed and fixed, we'll credit you in the release notes unless you prefer to
remain anonymous.
